# Яндекс.Расписания

## Назначение

Backend получает расписание рейсов/остановок через API Яндекс.Расписаний и отдаёт фронту уже свои эндпоинты (кэш в MongoDB — по мере реализации, чтобы не жечь лимит).

## Лимиты

- **500 запросов в день** на один API-ключ.
- Любые **реальные HTTP-запросы к API** (в коде, скриптах, из IDE/агента) — **только после явного подтверждения** человека.

## Ключ

- Хранится в переменной окружения `YANDEX_RASP_API_KEY`.
- Локальный файл: `Транспорт Севера/.env` (в git не входит).
- Шаблон: `Транспорт Севера/.env.example`.

После клонирования репозитория скопируй пример и подставь ключ:

```bash
cp "Транспорт Севера/.env.example" "Транспорт Севера/.env"
# отредактируй .env
```

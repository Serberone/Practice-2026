# Структура и стек

## Стек

| Слой | Технологии |
|------|------------|
| Backend | Python, FastAPI |
| Frontend | React |
| БД | MongoDB |

## Код приложения

Корень проекта: **`Транспорт Севера/`**

Планируемая раскладка:

```
Транспорт Севера/
├── backend/    # FastAPI, работа с MongoDB и прокси к внешним API
├── frontend/   # React
├── .env        # секреты локально (не коммитится)
└── .env.example
```

## Git

Git-репозиторий — **корень рабочей папки** на диске (документация + код; имя каталога может отличаться от названия на GitHub).

Ключи и токены **не попадают в коммиты**: только `.env.example` с пустыми/фиктивными значениями. Реальные значения — в `.env` на машине разработчика (см. `.gitignore`).
